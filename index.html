CAD → print

Most evenings the printer is running. For now I mostly print other people's files — the next step is printing my own: parts modelled from scratch, tested, fixed, printed again.

AI → software

I don't write code — I vibe-code. I describe the idea, the AI writes it, and I steer the design until it feels right: games, the tools above, small programs.

Currently: learning to design for print — tolerances, overhangs, and why the first layer is everything.

06

Workbench

A small Blender in the browser, made for printing. Object and Edit Mode, extrude and inset, G / R / S with axis locks, an outliner — then check the model in the Print tab and send it to the printer above.
